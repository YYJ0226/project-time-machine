## 本地验收

2026-10-17 最终检查：88 个单元测试通过；8 项隔离生产 HTTP 回归通过；lint 与生产构建通过。运行依赖审计为 0 项；开发工具链的 5 个告警单独保留说明，不将其隐去。

```bash
npm run lint
npm run test
npm run build
npm run test:http
npm audit --omit=dev --audit-level=high
```

HTTP 回归覆盖：公开探针与响应头；缺失配置失败；首页和登录页可用；回调忽略伪造主机头；私人导出鉴权；匿名分享仅呈现确认内容并转义 HTML；下次请求重新检查撤销；错误令牌不触发身份服务。

较旧 npm 的审计请求曾遇到 registry 已弃用接口错误；改用当前 npm 11 重新审计后，运行依赖为 0 项。没有为此升级项目框架、重写依赖锁或改变机器的全局 Node 配置。旧 npm 遇到该错误时应更新审计工具，不能把网络／接口失败视为审计通过。

`test:http` 自动构建 `.next-smoke` 并使用临时端口，与当前开发页隔离；无需退出 GitHub、真实授权或真实调用 AI。它不是浏览器交互测试，也不是实际云端分享测试。

本地 `.env.local` 含本机代理和维护密码、没有正式 `APP_ORIGIN`，因此 `/api/ready` 或生产配置检查返回未就绪是正确结果。不要删除现有开发配置来掩盖它；下一检查点在 Vercel 使用必要变量白名单。
