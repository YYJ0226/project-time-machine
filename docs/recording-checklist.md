- [ ] 时间线筛选、2× 缩放、单步／播放／暂停和聚焦模式已排练。
- [ ] 历史 AI 输入条数与当前证据不同的提示清楚可见，未现场等待新 AI 生成。
- [ ] 两份 Markdown 能下载；事先检查下载目录不会露出其他私人文件。

## 回看成片

- [ ] 文件能从头播放到尾，非空文件；画面和声音同步、无长时间黑屏。
- [ ] 文字和证据标题清晰，鼠标操作可辨；讲解时长符合课程要求。
- [ ] 前 30 秒说清“服务谁、解决什么问题”，而非只罗列技术栈。
- [ ] 至少展示需求、代码／PR、测试三类真实证据，并能回到 GitHub 原文。
- [ ] 展示一次时间线定位或回放，说明不是历史文件系统重建。
- [ ] 区分原始事实、AI 推断、人工确认、历史样本；没有把提示或成功 CI 说成全部质量已保证。
- [ ] 教师页确实无需登录且不可编辑；录像不暴露可用完整分享链接。
- [ ] 没有环境变量、令牌、Cookie、私人通知、无关文件和个人信息。
- [ ] 演示或字幕里没有虚构手机验收、线上新 AI 调用、Release 发布或尚未执行的测试。
- [ ] 下载材料、成片和讲稿的版本一致，或已说明各自截取时间和差异。

## 录后

- [ ] 本人验收成片后，再决定 PR 合并、正式版本标记和课程提交；本步骤不自动完成这些动作。
