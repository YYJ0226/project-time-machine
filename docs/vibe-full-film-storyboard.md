# 《开发的来路》五分钟整片分镜

日期：2026-10-17。本片在已验收的三十秒样片基础上扩成五至七分钟整片，顺序按课程要求：动机／需求 → 技术路线 → 实验展示 → 边界与结论。唯一案例是 Project Time Machine 自身。

- 交付物：`video-vibe/renders/final.mp4`（1920×1080、30fps、无旁白），工程源码在 `video-vibe/`。
- 事实表：[`vibe-film-facts-and-hooks.md`](vibe-film-facts-and-hooks.md)。本片新增的数字在下文“数字来源”一节逐条列出。
- 外观：夜曲（`night`）。全片一个世界：**夜里的装订工坊**。所有材料是纸、卡片、册页、尺、印章、打字机、抽屉和门；没有悬浮方框、连线图冒充主体。

## 一句话论点

最终页面只说明“做成了什么”；把需求、修改和验证的来路接起来，才能说明“它怎样被做出来”，以及哪些地方还不能下结论。

## 贯穿形象与颜色

- **过程册**：开场是它的封面（真实首页），中段是它被装订、上轴、盖章、打字、上锁、交付，结尾合上。
- **卡片**：每一页证据都是一张有类型的纸卡（ISSUE / COMMIT / PULL REQUEST / CHECK），带编号和一句原文节选。
- **尺**：时间轴是一把带刻度的长尺，回放是尺上的游标。
- 颜色全片只表达四件事：
  - 冰蓝 `#64E3F6`：来自 GitHub 的原始记录；
  - 金 `#F8D893`：人工确认过的关系、关键结论；
  - 灰虚线：规则提出的建议，尚未核对；
  - 玫红 `#E84B75`：冲突、失败、未完成。
- 字幕区（纵向 80%–95%）只在字幕出现时使用，任何装置最低点不低于 y=840。

## 示意与边界

- 册页、卡片、装订台、传送、盖章、开合门都是**证据组织示意**，不是产品真实录屏或真实点击；真实界面只在第 1、6、34、47、57 镜以截图出现。
