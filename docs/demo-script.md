# 课程演示与录屏脚本

这是可直接排练的约四分钟讲稿，不是已经录好的视频。实际时长以排练为准，录制前根据课程要求调整；不把功能界面示例当作真实证据。

## 录制前

- 使用已验收版本，关闭通知和无关页面，隐藏 `.env.local`、服务商控制台、账号设置及终端认证命令。
- 演示时使用同一个已登录浏览器；老师只读页另用无登录窗口验证。线上地址尚未部署时明确说“本地演示”。
- 事先同步证据并核对更新时间。选定需求 #3 → PR #4 → CI 的已确认链条，避免现场被 API 限流打断。
- 事先生成、核对草稿。不要在镜头中等待 AI 生成，不隐去失败记录，不把 AI 推断说成事实。
- 教师快照在确认分享范围后临时创建，录制后撤销。不要把仍有效的完整能力链接放在公开视频或公开文档中。

## 排练验收

记录一次实际排练的用时和出错点，再决定是否重录。不要提前写“无中断演示已通过”。成片应至少清晰展示三类原始证据、一次时间线定位、AI 与事实的区别，以及教师无登录访问和撤销结果。

建议交付目录由本人确认后再整理视频、封面和字幕；本检查点不创建空白视频文件，也不把脚本改名为视频充数。
