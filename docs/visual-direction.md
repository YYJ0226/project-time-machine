# 视觉方向：软件项目观测站

## 核心隐喻

界面不是传统管理后台，而是一座“软件项目观测站”。用户面对的是项目留下的事件信号：需求出现、代码变化、测试通过、AI 参与。中央时间轴像观测仪器，把分散记录对齐到同一时间坐标。

## 统一设计令牌

全站（首页、登录、项目工作台、证据工作台、时间线、审稿交付、教师只读页、404 与错误页）共用同一套 CSS 变量（定义于 `src/app/globals.css`），四条证据轨道的颜色在任何页面含义完全一致：

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Deep orbit (`--bg`) | `#050B16` | 全站深空背景与环境光层 |
| Instrument (`--surface`) | `rgba(12, 24, 41, 0.72)` | 玻璃态观测面板、卡片与导航表面 |
| Frost (`--text`) | `#EDF3F8` | 主要文字与高亮刻度 |
| Requirement (`--signal-requirement`) | `#F2B84B` | 需求信号（Issue）、决策与关键节点 |
| Code (`--signal-code`) | `#8B91FF` | 实现信号（Commit / PR）与主视觉光晕 |
| Verification (`--signal-verification`) | `#64D8D1` | 验证信号（CI Check）、同步与已确认关系 |
| AI (`--signal-ai`) | `#94A3B8` | AI 调用留痕（未确认草稿以虚线区分） |

字体使用 Geist 处理拉丁字符与界面数字，中文回退到系统无衬线字体（PingFang SC / HarmonyOS Sans SC / Microsoft YaHei UI 等）。等宽字体 Geist Mono 只用于提交哈希、时间戳、规则评分和证据编号。

## 共享导航与结构

- **品牌标识（`src/components/brand.tsx`）**：统一的 SVG 轨道徽标（外环、运行弧线、琥珀信号点）与自定义 `src/app/icon.svg` 站点图标。
- **项目内导航（`src/components/project-nav.tsx`）**：进入任意项目后，在「证据工作台」「时间线与回放」「审稿与交付」之间保持一致的顶部导航与面包屑。
- **首页观测舞台（`src/components/sample-observatory.tsx`）**：居中叙事与可交互的四泳道观测仪，点击任意节点或切换自动回放即可预览证据下钻与已确认关联；页面同时明确区分样例数据与真实工作台。

## 交互原则

- 动效用于表现“信号被捕获与回放”，克制克重，并完整尊重 `prefers-reduced-motion`。
- 颜色编码始终配合文字标签或图形符号（实心点 / 虚线环 / 符号标签），不只靠颜色传达状态。
- 所有可交互元素具备清晰的琥珀色键盘焦点环（`:focus-visible`）。
- 公开边界视觉显性化：原始事实、学生说明、未确认 AI 草稿与已确认叙事在每一处页面均一眼可分。
