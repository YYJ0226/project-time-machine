# 阶段五：AI、教师审阅与交付

状态：已实现并完成本地／云端联调，等待用户验收。不进入阶段六部署。

## 从哪里开始

打开项目证据页或时间线，点击“审稿与交付”。页面左侧为私人审稿区，右侧为交付控制，下方为新快照和导出的内容预览。手机上按相同顺序纵向排列。

验收建议：

1. 查看已有真实 DeepSeek 草稿，展开“核对引用原文”。正文中的“证据1”等短标签与引用列表一一对应，数据库保存真实 UUID。
2. 修改阶段摘要、提醒和讲解稿，点击“确认这份文字”。也可忽略或在任务账本重新审阅旧版本。只有已完成且人工确认的文字能进入交付；没有确认版本时仍可交付原始事实。
3. 在交付预览中核对仓库、证据、已确认关系以及 AI 标识。注意这是缓存采集状态，不代表 GitHub 此刻的状态；必要时先回证据页同步，再重新生成草稿。
4. 选择 1／7／30 天有效期，勾选分享范围确认，创建只读快照。完整链接只显示一次；丢失后创建新链接即可，旧链接可撤销。
5. 在未登录的浏览器打开链接，核对没有编辑入口、未确认草稿或私密配置。撤销后刷新应显示“此审阅链接不可用”。
6. 下载 Markdown 报告和视频讲解提纲。没有确认版本时，报告明确只整理原始事实，讲解提纲明确是固定结构而非 AI 生成稿。

真实生成的草稿故意保留为待确认，不能把自动化联调代替用户对结论的认可。

## 配置

依次执行 `supabase/migrations/` 中三份迁移。新增迁移为：

```text
20261016000300_create_delivery.sql
```

可使用 Supabase Dashboard SQL Editor，或已认证并链接的 Supabase CLI：

```bash
supabase db push --dry-run
supabase db push
```

本地忽略文件 `.env.local`：

```dotenv
DEEPSEEK_API_KEY=填入自己的密钥
DEEPSEEK_MODEL=deepseek-flash
```

也支持 `deepseek-v4-pro`。更换配置后重启开发服务。密钥只在服务端使用，绝不能使用 `NEXT_PUBLIC_` 前缀，不能放进 README、Issue、截图或 Git 提交。

真实调用会产生 API 用量；页面按钮旁明确列出发送范围。未配置密钥时给出配置提示，不生成模拟结果。每个项目至少间隔 60 秒调用，数据库唯一索引阻止同项目并发任务；75 秒超时，不自动重试计费请求；超过两分钟的中断任务在下次生成时标记失败。

请求固定发送至 `https://api.deepseek.com/chat/completions`，关闭 thinking，使用 JSON 输出，限制 3500 输出 tokens。最多输入最近 60 条公开证据的标题（每条最多 300 字符）、类型、时间、状态和短引用标签，不发送证据正文、仓库文件或环境变量。源标题是不可信数据，不能当作指令；模型输出仍可能错误，人工核对不可省略。

参考：[DeepSeek Chat Completion](https://api-docs.deepseek.com/api/create-chat-completion/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)。模型可用性和费用以服务商当时的配置为准。

## 数据与权限边界

- `ai_runs`：项目／所有者、调用状态、模型、提示词版本、输入摘要哈希、输入证据 ID、原始生成结果、人工审阅结果、用量和安全错误码。未保存完整实际输入提示词，也不保存密钥。
- AI 生成的未知引用、空正文、截断输出会被拒绝，不将其变为可交付草稿。短标签经校验后映射回真实证据 UUID。
- 交付使用最新人工确认版本，独立查询，不会因为随后产生 30 个草稿而漏掉确认版本。撤销一个确认版本后，可能回退到更早的确认版本；以交付预览为准。
- `review_shares`：256 位随机能力令牌，数据库只保存 SHA-256 哈希；固定快照和到期时间不可由应用角色修改，只允许所有者撤销。任何持有完整链接的人均可读，不是“只有指定老师可读”。
- 匿名角色只能通过窄 RPC `get_public_review` 读取单个有效快照，不能直接枚举分享表或读取 AI 草稿。RPC 固定空 search_path，检查令牌、到期、撤销与项目公开性。
- 快照白名单仅包含仓库名／公开 URL、证据标题／状态／时间／来源 URL／ID、已确认关系、人工确认 AI 文字及其标识。排除原始正文、source_data、所有者 ID、完整提示词和环境变量。常见密钥形态做额外遮蔽，但这不是全面 DLP，发布前仍需核对。
- 教师页不读取 Cookie、不调用登录接口，不依赖 Service Role。响应设置 no-store、no-referrer 和 noindex；打开外链不发送能力链接作为 Referer。教师页展示普通文本，不执行模型生成 HTML。
- 导出仅项目所有者可下载，使用与分享相同的字段投影；AI／手工编辑文字在 Markdown 中转义，避免变成伪造链接或 HTML。
- 旧快照不跟随编辑或审阅变化。需要停用旧内容时主动撤销对应链接，重新创建快照。撤销不能召回截图或已下载文件。
- 当前导出最多 1000 条证据、1000 条已确认关系；超限停止交付并明确报错，不静默漏项。AI 只归纳最多 60 条样本，不声称完整覆盖。
- 账本列表显示最近 30 次调用；私人时间线 AI 泳道显示最近 100 次任务元数据，而非把未确认草稿当作源事实。

## 数据库权限回归

`supabase/tests/delivery-security.sql` 包含匿名读取、错误令牌、过期、撤销、跨用户访问／插入以及快照／到期时间不可修改测试。使用已导入至少一个项目的数据库；测试事务结束会全部回滚，不保留测试分享。

从项目 Connect → Session pooler 复制实际连接信息；从数据库设置下载根证书。仅在本地设置：

```dotenv
SUPABASE_DB_HOST=自己的池化连接主机
SUPABASE_DB_USER=postgres.自己的项目引用
SUPABASE_DB_PASSWORD=自己的数据库密码
SUPABASE_DB_CA_FILE=C:/自己的路径/prod-ca-2021.crt
```

```bash
npm run test:db
```

脚本使用验证 CA 和主机名的 TLS，不接受关闭证书验证的替代方案。数据库密码仅用于维护测试，网页运行不需要它。[Supabase SSL 说明](https://supabase.com/docs/guides/platform/ssl-enforcement)。

## 已知边界与下一阶段

本阶段不部署公网，因此 `localhost` 分享只能当前电脑访问。教师页是固定的纵向证据时间线，不是拥有编辑权限的私人工作台，也不提供历史代码文件还原。AI 提醒只表示当前样本未显示，不能证明某项工作没有发生。用量记录不等于费用账单。

后续阶段再做部署、性能和质量加固、真实视频制作。开发工具依赖的审计告警需继续处理；本次 `npm audit --omit=dev` 为 0 项。不要直接执行 `npm audit fix --force` 引入未经验证的破坏性升级。
