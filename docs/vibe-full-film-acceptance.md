## 制作方式

- 沿用用户指定的 [vibe-knowledge-film](https://github.com/HeyChengC/vibe-knowledge-film) 方法：无旁白、底部一行字幕、每句字幕在屏上演出；提问、命名、结论不硬配图。引擎固定在上游 `62d5150` 的本地改造版。
- 一个世界：夜里的装订工坊。贯穿道具是过程册、证据卡（ISSUE / COMMIT / PULL REQUEST / CHECK）、钥匙、黄铜印章、打字机、抽屉、带期限的门，以及一根时间轴长尺。颜色只表达四件事：冰蓝＝原始记录，金＝人工确认，灰虚线＝未核对的建议，玫红＝冲突、失败、未完成。
- 真实界面只以截图出现：线上首页（2026-10-17）、Issue #3、PR #4、GitHub Actions 列表。纸页、装订、盖章、开门均为**证据组织示意**，不是产品真实点击或新发生的审批。

## 音乐

- 用户指定歌曲 [We Never (Remix)](https://music.163.com/song?id=3443610299)，本地 189.8 秒、48 kHz 双声道。
- 原曲不足以覆盖 300 秒，因此做两段式剪辑：0–151.5 秒 + 38–188 秒，在 150 秒附近以 1.5 秒交叉淡化接续；全片 −8 dB 增益、0.5 秒淡入、3.5 秒淡出。剪辑点只落在章节边界，不逐镜卡点；算法给出的 BPM 候选不作为结论。
- 不新增配音与音效。音轨、混音与成片只在本地，未提交 Git；公开传播授权未核实。

## 自己看过的部分（第一轮）

第一轮用 58 张同刻静帧自查，发现并修掉：

| 问题 | 处理 |
| --- | --- |
| 多处画面与字幕时间错位（该出现的没出现、已退场） | 全部章节改为按字幕绝对时间驱动（`WS.beat`），相机按 `WS.camTrack` 关键帧 |
| 主体偏小、上半屏空 | 成果页放大到 1040×585；卡片 350–500 px；角落材料摞放大三分之一 |
| 检查卡压住字幕 | 移到 `CHECK` 卡 720–870 区域，三卡改为上方两卡、下方一卡 |
| 翻面时出现“纸片侧面”一帧 | 翻面缩短到 0.5 秒并错开 |
| 未完成页与首页之间有约 4 秒空屏 | 未完成页延长到 281 秒，与首页交叠淡出 |
| “拼出来的 vs 真实记录”右侧点被裁出画面 | 整体缩小 1.22 倍并居中 |

## 技术验证

- 源码检查 `node --test video-vibe/source.check.mjs`：5 项通过（300 秒／30fps、字幕时序与长度、章节边界、引用与示意标注、章节装载）。
- 服务边界检查 `python -m unittest discover -s video-vibe -p test_server.py`。
- 浏览器离线检查 `python video-vibe/verify.py`：字幕窗口、单句最长时长、字体加载、1920×1080 画布约定。
- `--det` 确定性自检。
- 导出校验 `python video-vibe/verify_export.py`：实际解码 9000 帧、300 秒、H.264 / AAC 48 kHz 双声道，并记录 SHA-256。
- 成片 SHA-256：`366dc13e0f6363cfc90efc9b16ea7fce2ef536753388a839558c2bc7fc6740df`；探测结果保存在 `renders/final.qa.json`。
- 成片音轨解码实测：300.01 秒、峰值 −4.35 dBFS、平均 −17.79 dBFS（AAC 编码后略高于源 WAV 的 −6.53 dBFS 峰值读数，属编码峰值差，无削波）。
- 拼接说明：74–78.4 秒原为近空屏，补渲 `patch74.mp4`（73.5–78.5）后与前后片段重编码拼接，拼接处已抽查 73.4 / 73.6 / 74 / 76 / 78.4 / 78.6 六帧，画面连续。
