## 先前候选：番茄钟（已停止作为视频主线）

“给学生整理开发历史的平台”是抽象概念；“我给番茄钟修了什么、老师如何查证”更容易理解。主角仍然是 Project Time Machine，番茄钟只是输入平台的实验对象，不能把视频做成番茄钟产品广告。

C1 调查时只读检查 [YYJ0226/pomodoro-timer](https://github.com/YYJ0226/pomodoro-timer)，基线提交 `4edfb9ae0998c8ef742407efffa5c06b3e032557`（提交时间 2026-07-01）。基线是 Python Tkinter 桌面应用，包含开始／暂停／重置、工作／休息、自定义时间、提示与内存完成计数；当时仓库仅四个文件，没有测试和 CI 文件。下列是当时观察，后续 P1 的实际结果单独记录。

代码观察，不冒充已运行复现：

- `apply_settings` 将两个输入直接转成整数并顺序写回；没有在写入前校验完整范围，也没有拒绝零或负数的显式检查。
- `update_display` 以工作或休息总时长作分母，边界值值得建立回归测试。
- 计时线程直接调用界面更新；计时状态、调度与 Tk 界面耦合，需要先分离后测试暂停、重置和模式切换。
- 完成计数只在内存中，退出后不持久化；`long_break` 已定义但当前切换逻辑仍使用短休息。

这些观察用于确定待验证项；不先声称“已修复”，也不凭源码阅读虚构实验通过率。

## 视觉与声音方向

- 1920×1080、16:9、30 fps 为建议输出，不是老师已指定格式。
- 沿用平台深蓝背景 `#07111f`、面板 `#0d1c2c`、浅色正文 `#eaf2f5`、青色 `#64d8d1`；紫色／琥珀只区分证据类型和状态。番茄红只在案例出现，不取代主片视觉。
- 开场用“散落记录 → 连续证据”的形变，技术路线用数据流动，实验用真实画面定向推近与重点标注。不是整片贴静态截图，也不是每句话都炸光、转场或飞入。
- 口播时每镜只突出一个结论，技术图与 UI 给阅读停留；字号以 1080p 回看可读为准，不用小字堆源码。
- 中文自然解说、无真人模仿；GitHub、Supabase、Commit、PR 等统一读法。音乐不盖人声，优先无音乐版核对内容，授权音乐可后配。
- 不复制第三方品牌 Logo／演示产品页面冒充我们的软件，不打包无授权字体，不展示密码、Cookie、服务商控制台或完整教师能力链接。
- 网页实拍使用当前授权的浏览器工具；第三方 skill 的采集脚本不能绕过当前工具限制。番茄钟是原生 Tk 桌面程序，若当前环境仍不提供原生窗口采集，则由本人提供真实截图／短录屏；可先用真实 Git 证据和明确标注的概念动画做技术样板，不手绘一个假界面冒充运行结果。
